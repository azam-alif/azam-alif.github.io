The Components

Since, an neural network for reseach work or commercial work is very much broad topic, we first need to understand the relation between conda, pip, tensorflow, cpu, gpu and package version. all things need to be compatible so that the whole project runs smoothly. So, first we need to understand this layer by layer to get the full picture in our mind.

In our operating system, we always different kind of softwares. Usually we dont care about the version of those softwares, but when we are working on something production level, we must manage versions properly. And in one computer we can be working on separate projects that may lead to a version mismatch. So, we need a virtual environment for each project. This this as a little box inside a bigger box. The bigger box is the full operating system and small box is you own little project corner where you can download whatever you want and don't get mismatched with other things. To create and manage this little box, we are gonna use micromamba.

Inside this virtual environment, we need to download everything of appropriate versions. Since training will happen in GPU, cuda is needed to manage nvidia gpu's. We can download cuda in this virtual environment using micromamba. We will need tensorflow since it will help us in not writing cuda directly. And some packages like numpy, matplotlib of specific version can be download by python package manager pip.

Train the DeBCR model

First clone the repository. Then run setup.shto download the relevent packages and dependencies, download the dataset. If you get All ok message in the end, then your system is ready to train the model. Then run train_local.py and the training will begin. it took 25 minutes in my NVIDIA Tesla T4 gpu.
